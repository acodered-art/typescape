# TypeScape — Feature Brainstorm

## Competitive Gaps & Opportunities

### What PDB Users Hate (Our Opportunities)
- **Toxic community** → Positive, moderated, gamified community
- **Stereotyping, no nuance** → Evidence-based typing, multiple systems, cross-correlation
- **Enneagram treated as secondary** → Every system is first-class with independent voting
- **No social features** → Friends, groups, messaging, matchmaking
- **No gamification** → Streaks, badges, leaderboards, challenges
- **No AI/personalization** → AI insights, dynamic content, coaching
- **No data visualization** → Charts, trends, comparisons
- **No API** → Developer tools, browser extensions, integrations
- **No mobile app** → PWA + native wrapper
- **Poor moderation** → AI moderation, user reporting, type verification

### What Would Make TypeScape "Sticky" (Daily Returns)

#### Social Features (Phase 3)
- [ ] User profiles with customization (avatar, bio, type story)
- [ ] Following/friends system
- [ ] Activity feed (what friends are typing)
- [ ] Private messaging
- [ ] Type-based groups (e.g., "ENFJ Support Group")
- [ ] Collaborative typing ("Help me type this character!")
- [ ] Live typing sessions
- [ ] "Type me" posts (upload yourself for community typing)

#### Gamification (Phase 3-4)
- [ ] Daily challenges ("Type 3 characters today")
- [ ] Weekly quests ("Complete your Enneagram wings profile")
- [ ] Streaks ("7-day typing streak")
- [ ] Leaderboards ("Top typers this week")
- [ ] Progress bars ("Your Big Five journey: 60% complete")
- [ ] Unlockable content (career insights after 5 logins)
- [ ] Surprise badges, random challenges

#### Comparison & Matching Tools
- [ ] Type compatibility calculator (friendship/romance)
- [ ] Career matching per type
- [ ] Celebrity/character matching ("Which character matches you?")
- [ ] Side-by-side type comparison
- [ ] "Users who typed X also typed Y" recommendations

#### Content & Education
- [ ] Type-specific articles ("How to communicate with an ISTP")
- [ ] Myth-busting content ("Debunking MBTI stereotypes")
- [ ] Video courses / podcasts
- [ ] Type-based challenges ("30-day MBTI growth")
- [ ] Academic resources (peer-reviewed links)

#### Data Visualization
- [ ] Interactive type charts (radar, bar, function stack)
- [ ] Trend tracking ("Your votes over 6 months")
- [ ] Population comparison ("How you compare to others")
- [ ] Enneagram growth path visualization
- [ ] Personality heatmaps (strongest/weakest traits)

#### Quality of Life
- [ ] AI comment moderation (auto-flag toxic/stereotyping)
- [ ] User reporting system
- [ ] Type verification ("Submit evidence for your type")
- [ ] Customizable feeds (hide toxic users)
- [ ] Offline mode (PWA)
- [ ] Accessibility improvements

#### Platform
- [ ] Public API for developers
- [ ] Browser extension (see type on Twitter/LinkedIn)
- [ ] Dating app compatibility integration
- [ ] Mobile PWA with push notifications
- [ ] Embeddable widgets (TypeCard for external sites)

### Priority Build Order

| Phase | Feature | Impact |
|-------|---------|--------|
| **Now** | Activity feed / following | High — makes it social |
| **Now** | Daily challenges / streaks | High — drives daily return |
| **Next** | Type comparison tools | High — unique value |
| **Next** | Content articles | Medium — SEO + education |
| **Later** | Data visualization | Medium — polish |
| **Later** | API + integrations | Medium — ecosystem |
| **Later** | Mobile PWA | Medium — accessibility |
| **Later** | Browser extension | Low — reach |
